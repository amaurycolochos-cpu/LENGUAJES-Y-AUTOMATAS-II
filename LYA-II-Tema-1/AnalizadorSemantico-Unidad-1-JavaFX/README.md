# Analizador semántico

Proyecto en JavaFX para las actividades 1.2 y 1.3 de Lenguajes y Autómatas II.

- JDK 17.
- Maven 3.8 o posterior.
- Visual Studio Code con Extension Pack for Java.

- `AplicacionAnalizador.java`: inicia la ventana.
- `AnalizadorController.java`: conecta los botones y resultados con el analizador.
- `analizador-view.fxml`: contiene la estructura de la interfaz.
- `styles.css`: contiene los estilos.
- `AnalizadorSemantico.java`: procesa declaraciones, asignaciones y salidas.
- `AnalizadorExpresiones.java`: evalúa las expresiones.
- `ejemplos/`: contiene las pruebas de las actividades 1.2 y 1.3.
